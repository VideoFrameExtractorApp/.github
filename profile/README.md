## Extract frames from a video in Chrome

1. **Install** [Video Frame Extractor](https://chromewebstore.google.com/detail/video-frame-extractor/mcmdhhpbgmkeggmfhclacdkhbdgohfak?utm_source=github&utm_medium=org&utm_campaign=profile) from the Chrome Web Store.
2. **Open a video**: a file from your computer, or any video playing in a tab.
3. **Pick a mode**:
   - *Scene changes*: one frame per slide or shot
   - *Every N seconds*: a frame at a steady interval
   - *Manual*: step with ← → and save exactly the moment you want
4. **Save** the frames as JPG, PNG or one PDF. Quick capture: **Alt+Shift+S** saves the video area in one keystroke.

## Extract frames from a video in ChatGPT or Claude

1. Install the plugin ([ChatGPT](https://github.com/VideoFrameExtractorApp/video-frame-extractor-chatgpt#how-to-install-the-plugin-in-chatgpt) · [Claude](https://github.com/allenmagic8888/video-frame-extractor-claude)).
2. Attach a video (MP4, MOV, WebM, MKV) to the chat.
3. Ask in your own words: *"Summarize this video with times"*, *"Script and shot list of this TikTok"*, *"A PDF with one frame per slide"*.

## Common use cases

- **Lecture video to PDF**: all slides of a recorded lecture or webinar in one file
- **Exact frame**: a sharp still at 1:23 for a thumbnail, a blog post or a bug report
- **Storyboard**: one frame per shot to study how a video, ad or TikTok is edited
- **Video summary with AI**: let ChatGPT or Claude read a video and write notes
- **Screen recording to steps**: every new window or dialog as its own frame
- **Dataset images**: frames every N seconds for training or research
